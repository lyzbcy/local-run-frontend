本地运行前端项目

集中启动常见前端项目，无需向项目添加预览脚本
替代每个项目都要重跑一次的预览脚本，Mac / Windows 统一管理
v0.4.0
Mac · Apple 芯片 Mac · Intel 芯片 Windows · x64 安装版 源码（GitHub）

它能解决什么

接手每一个前端项目，都要先搭一套本地预览——脚本不能 git 上去，同事用不了，下次还要重来。

痛点：每个项目都要重新跑一套预览工具，不能提交版本库，换个人接手就没了，浪费时间和 token。
解法：装一次这个软件，统一管理所有前端项目，无需复制预览脚本，同事也能独立安装使用。

自动识别项目

选目录即自动判断是静态站、Vite、Next、Vue、CRA 还是 Nuxt，给出对应启动方式。

一键启动

端口自动顺延、健康检查通过才开浏览器，先打开自动生成的目录页。

无需添加预览脚本

软件不向项目添加预览脚本；框架自身仍可能生成缓存和编译输出。

端口管理

一目了然看到本机在跑哪些预览服务，可单独停掉，启动时自动避让占用端口。

AI Agent 接入

提供本地 HTTP 接口 + Prompt，让 Cursor/Claude/ZCode 用自然语言控制启停。

项目记忆

我的项目 / 收藏 / 最近，一次添加，下次直接一键打开，不用再拖目录。

三步上手

装好软件，选择目录，再启动预览

1

下载安装

v0.3.0 升级请手动下载本页安装包。旧版内置更新器有替换失败风险，本次修复从 v0.4.0 起生效。

Mac（推荐 DMG）：按芯片下载 DMG（Apple 芯片选 arm64，Intel 选 x64），双击打开，把左侧应用图标拖到右侧 Applications 文件夹即完成安装。首次打开若被拦：系统设置 → 隐私与安全性 → 「仍要打开」，或直接用应用内的「一键去除隔离」引导。也可下载 ZIP 解压后运行「一键安装.command」。需要 macOS 12+。
Windows：Windows 10+ x64，运行安装 EXE；未签名安装包可能显示系统提示，请核对来源后继续。

2

添加项目

点「添加项目」选目录，或直接把文件夹拖进窗口。静态项目无需 Node.js；框架项目需先安装依赖，Node.js 按项目要求选择，建议 22+。特殊启动命令、环境变量和后端依赖仍需按项目配置。

3

一键启动

点「启动」，自动起服务、健康检查、打开浏览器和目录页。改了代码点「重启」即可。

主要功能

清爽的项目管理界面，一目了然看到哪些在跑

项目管理主界面
我的项目 / 收藏 / 最近，一键启动、重启、定位、收藏
网关端口管理

AI Agent 接入
复制 Prompt 给 Cursor/Claude，用自然语言控制启停

以上为功能示意，并非软件截图。Mac 关闭窗口后服务在后台保留；Windows 关闭窗口会退出并停止服务。

🤖 让 AI Agent 帮你启动项目

软件自带本地控制接口，你的 AI 助手能用自然语言管理项目

在 Cursor / Claude / ZCode 里说一句："启动 demo-admin 项目"，AI 会自动调本地接口、起服务、打开浏览器，把目录页链接发给你。
支持：启动 / 停止 / 重启 / 添加 / 删除项目。软件内「AI Agent」页签有一键复制的 Prompt。
