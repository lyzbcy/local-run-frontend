## 🚀 快速上手

- **跑起来**：`npm start`（需先 `npm install`，Electron 二进制走 npmmirror 镜像）
- **架构一句话**：Electron 壳 + 内嵌的静态预览服务器（zeen-tools 的精华），不向用户项目添加预览脚本，框架自身仍可能生成缓存
- **核心闭环**：选目录 → 自动识别项目类型 → 一键启动（端口顺延 + 健康检查）→ 打开浏览器（先开目录页）

## 📌 当前状态

- **版本**：v0.4.0
- **平台**：macOS 12+，arm64 / x64 ZIP（含 .app、安装脚本）；Windows 10+，x64 NSIS 安装 EXE
- **运行条件**：静态无需 Node.js；框架需安装依赖并满足项目 Node.js 要求，建议 22+
- **窗口行为**：Mac 关闭后后台保留服务；Windows 关闭后退出并停止服务
- **本轮修复**：批量导入保留全部新项目；未知项目保留自定义命令；Windows 原生窗口控制；静态预览路径与 URI 边界、仅子目录页面的目录页
- **发布说明**：未签名安装包可能触发系统提示。下载入口见根 README；最终发布及平台验证状态以 Release 为准。
