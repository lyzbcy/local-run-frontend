本地运行前端项目

一键启动任意前端项目，不往项目里写任何文件
替代每个项目都要重跑一次的预览脚本，团队共享、永远在线
v0.2.0
下载 Mac 版 源码（GitHub）

它能解决什么

接手每一个前端项目，都要先搭一套本地预览——脚本不能 git 上去，同事用不了，下次还要重来。

痛点：每个项目都要重新跑一套预览工具，不能提交版本库，换个人接手就没了，浪费时间和 token。
解法：装一次这个软件，统一管理所有前端项目，零文件侵入，团队共享，永久在线。

自动识别项目

选目录即自动判断是静态站、Vite、Next、Vue、CRA 还是 Nuxt，给出对应启动方式。

一键启动

端口自动顺延、健康检查通过才开浏览器，先打开自动生成的目录页。

不写任何文件

所有预览能力都在软件内部，绝不往你的项目目录写一个文件，可以放心 git。

端口管理

一目了然看到本机在跑哪些预览服务，可单独停掉，启动时自动避让占用端口。

AI Agent 接入

提供本地 HTTP 接口 + Prompt，让 Cursor/Claude/ZCode 用自然语言控制启停。

项目记忆

我的项目 / 收藏 / 最近，一次添加，下次直接一键打开，不用再拖目录。

三步上手

从安装到启动一个项目，不到一分钟

1

下载安装

下载 .app，拖进「应用程序」。首次打开若提示"已损坏"，运行随附的一键安装脚本即可。

2

添加项目

点「添加项目」→ 选择一个前端项目目录 → 自动识别类型 → 确认添加。

3

一键启动

点项目卡片上的「启动」，自动起服务、健康检查、打开浏览器和目录页。
