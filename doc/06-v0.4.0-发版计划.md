# v0.4.0 双平台发版计划

目标：发布可下载的 macOS arm64 / x64 应用包与 Windows x64 安装程序，同步 GitHub Pages 下载页。

保持 Electron + 原生 JS 架构。按系统处理 Node 探测、PATH、进程树回收；按框架生成端口参数。Mac 更新采用先暂存、再替换、失败恢复；Windows 下载并校验安装程序后启动安装向导。GitHub Actions 在三个原生系统构建和测试，全部通过后才公开 Release。

- [x] 基线：现有 59 项测试通过，2 个本机私人参考目录测试跳过。
- [x] 老田、土豆独立评审并处理阻断问题。
- [x] 运行器：补框架参数、Windows Node 探测、进程退出/失败回收与重复启动测试。
- [x] 数据与边界：导入合并回归、控制接口限制网页来源、预览路径边界。
- [x] 更新器：架构匹配、下载完整性、Mac 事务替换、Windows 安装程序更新。
- [x] 打包：Mac 双架构 zip（含安装脚本），Windows x64 NSIS exe；原生构建与启动冒烟。
- [x] 页面、README、版本号、发版说明同步。
- [x] 完成复审、打标签、构建；检查三个产物后发布，并核验线上下载。

验证边界：自动化验证覆盖安装包构建、应用窗口、临时静态项目及框架启停。未签名/公证的包需在下载页说明系统提示及安装方式。不能把构建成功等同于所有真实业务项目兼容。
