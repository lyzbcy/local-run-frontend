- **首次打开 quarantine 自助去除**：app 内自检 + 引导一键去除（osascript 提权），不再依赖用户跑脚本

#### 🔧 子代理对抗审查修复（main 进程）
- 🔴 main.js: `execFile` 未引入（quarantine 去除崩溃）→ 引入
- 🔴 osascript 路径转义注入风险（中文/空格/特殊字符）→ 改用 AppleScript `quoted form of`
- 🟡 updater: `app.exit()` 绕过 before-quit 导致端口/进程泄漏 → 加 onBeforeExit 钩子手动停服务
- 🟡 updater: 无下载完整性校验 → 加 size 校验 + 清理半下载文件
- 🟡 runner: `shell:true` + 仅 SIGTERM 父进程 → dev server 孙进程孤儿占端口 → 改 `detached:true` + 进程组 kill(-pid)
- 🟡 runner: `ELECTRON_RUN_AS_NODE: undefined` 脆弱 → 改 `delete`
- 🟡 托盘 setInterval 泄漏 + 每 2s 读磁盘 → 清理定时器 + 项目名缓存
- 🟡 control-server: 请求体无大小限制 → 2MB 上限
- 🟡 control-server /restart 等待不足（400ms < 1500ms SIGKILL）→ 改 1800ms
- 🟡 dev-nav: tokenConfig 空对象导致 UI 坏 → 空后端重新探测
