## 🚀 快速上手

- **跑起来**：`npm start`（需先 `npm install`，Electron 二进制走 npmmirror 镜像）
- **架构一句话**：Electron 壳 + 内嵌的静态预览服务器（zeen-tools 的精华），不往用户项目里写任何文件
- **核心闭环**：选目录 → 自动识别项目类型 → 一键启动（端口顺延 + 健康检查）→ 打开浏览器（先开目录页）
