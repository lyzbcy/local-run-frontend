## 1. Electron 安装（中国网络）

默认从 GitHub releases 下二进制会超时。用 npmmirror 镜像：

```bash
export ELECTRON_MIRROR="https://registry.npmmirror.com/-/binary/electron/"
export ELECTRON_CUSTOM_DIR="{{ version }}"   # 重要：npmmirror 用 version 作目录
npm install --save-dev electron
```

打包时同样要设：
```bash
export ELECTRON_BUILDER_BINARIES_MIRROR="https://registry.npmmirror.com/-/binary/electron-builder-binaries/"
```

验证：`node_modules/electron/dist/Electron.app/Contents/MacOS/Electron` 存在即成功。

## 2. 端口扫描顺延

参考 qv-admin 的 `一键启动前端.command`：

```js
// 在 [start, end] 区间找第一个空闲端口
async function findFreePort(start, end) {
  for (let p = start; p <= end; p++) {
    if (await isPortFree(p)) return p;
  }
  throw new Error(`端口 ${start}-${end} 全被占用`);
}

function isPortFree(port) {
  return new Promise(resolve => {
    const srv = net.createServer();
    srv.once('error', () => resolve(false));
    srv.once('listening', () => { srv.close(() => resolve(true)); });
    srv.listen(port, '127.0.0.1');
  });
}
```

优先复用项目上次记录的端口（`project.port`），被占了再顺延。

## 4. 框架项目启动（framework）

走子进程 `npm run dev`，需要：
- `cwd` = 项目路径
- **不继承 electron 的环境**，避免父进程是 Electron 导致某些包行为异常
- 解析 dev server 的实际端口（vite 默认 5173，但可能顺延）：
  - 方案 A：启动前 `--port <port> --strictPort` 指定，保证端口已知
  - 方案 B：扫 stdout 抓 `Local: http://...:PORT`
  - MVP 用 A：传 `--port <我们选的端口> --strictPort`，失败则顺延重试

## 5. 健康检查

```js
async function waitHealthy(url, { timeout = 60000, interval = 1000 }) {
  const deadline = Date.now() + timeout;
  while (Date.now() < deadline) {
    try {
      const res = await fetch(url, { signal: AbortSignal.timeout(2000) });
      if (res.status < 500) return true;
    } catch {}
    await sleep(interval);
  }
  throw new Error(`健康检查超时：${url}`);
}
```

## 6. 进程生命周期

- 启动的 server / dev process 注册到 `runningInstances: Map<projectId, { proc, port, url }>`
- app 退出（`before-quit`）时全部 kill
- 关闭单个：按 projectId 找到 proc，SIGTERM → 1s 后 SIGKILL

## 8. 项目识别（detector）

按顺序探针，命中即返回：

```js
function detect(root) {
  const pkg = readPackageJson(root);
  if (pkg?.dependencies?.['next'] || pkg?.devDependencies?.['next']) return { type:'next', start:'npm run dev' };
  if (pkg && hasDeps(pkg, ['vite'])) {
    // vue-cli 也可能有 vite，先看 vue.config 且无 vite
    return { type:'vite', start: pkg.scripts?.dev ? 'npm run dev' : 'vite' };
  }
  // ... nuxt / vue-cli / react-scripts
  if (hasHtml(root)) return { type:'static', start: null };
  return { type:'unknown', start: null };
}
```

## 9. AI-Agent 控制接口

内嵌 server 同时监听一个控制端点（或独立小 server）：

```
GET  /__ctrl__/projects        → 项目列表
POST /__ctrl__/start  {id}     → 启动
POST /__ctrl__/stop   {id}     → 关闭
GET  /__ctrl__/status          → 运行中的实例
```

绑定 127.0.0.1，端口固定（如 47800），agent prompt 里告诉这个 base url。

## 10. 更新检查

```js
async function checkUpdate(repo) {
  const r = await fetch(`https://api.github.com/repos/${repo}/releases/latest`);
  const j = await r.json();
  return { latest: j.tag_name, current: app.getVersion() };
}
```

GitHub API 不稳时的容错：失败静默，不阻塞用户。
