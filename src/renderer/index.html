🔌 运行中的端口
本软件启动预览时占用的端口会列在这里。启动新项目时会自动顺延选择空闲端口。可手动停掉某个端口的服务。
🤖 AI-Agent 接入
让你的 AI Agent（Cursor / Claude / ZCode 等）通过下面的本地 HTTP 接口控制本软件，实现「用自然语言启动/关闭前端项目」。
控制接口地址（POST/GET · 仅本机）
http://127.0.0.1:47800
可用端点
GET  /status          运行中的实例
GET  /projects        项目列表
POST /start   {"id"}  启动项目（自动开浏览器 + 目录页）
POST /stop    {"id"}  关闭项目
